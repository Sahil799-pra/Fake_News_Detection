# Fake News Detection

A machine learning and AI-assisted fake news detection project built with Python, Flask, HTML, CSS, and JavaScript. The app predicts whether a given news text is likely Fake or Real and can also use Gemini as an AI explanation layer for unseen text.

## Project Overview

This project is designed as a simple demo for fake news classification. It combines:

- a TF-IDF + Logistic Regression model trained on fake and real news data
- a Flask backend that serves predictions
- a frontend interface for users to paste article text and get results
- Gemini AI integration for extra explanation and analysis when an API key is available

## Features

- Enter article text in the web UI
- Predict whether the text is Fake or Real
- View confidence score
- Auto-train the model if trained files are missing
- Run the frontend and backend together from the same Flask app
- Optional Gemini API explanation for AI-assisted analysis

## How to Run

### 1. Open terminal in the backend folder

```bash
cd backend
```

### 2. Activate the virtual environment

```bash
source venv/bin/activate
```

### 3. Start the application

```bash
PORT=5001 python3 app.py
```

### 4. Open in browser

```text
http://127.0.0.1:5001
```

If port 5001 is busy, use another available port, for example:

```bash
PORT=5002 python3 app.py
```

Then open:

```text
http://127.0.0.1:5002
```

## Environment Variables

Create a `.env` file in the root project folder and add your Gemini key if needed:

```env
GEMINI_API_KEY=your_api_key_here
```

The backend loads this file automatically using `python-dotenv`.

## API Endpoint

### POST /predict

Request body:

```json
{
  "text": "This is a sample news article text to classify."
}
```

Example response:

```json
{
  "prediction": "Real",
  "confidence": 92.45,
  "ai_explanation": "AI explanation unavailable or generated by Gemini if the API is active."
}
```

## Model Training

The project trains a fake news classifier using:

- TF-IDF vectorizer
- Logistic Regression classifier
- cleaned and processed text data from the dataset

The training script is in:

- `backend/train.py`

## Dataset

The project uses fake and real news datasets stored in:

- `backend/data/`

The script automatically reads the dataset and trains the model if the model files are missing.

## Important Note

This is a demo ML project and should not be treated as a final fact-checking system. Fake news detection is a difficult task because models can learn source, style, and wording patterns rather than true factuality.

The Gemini integration is meant to help with AI-assisted review, but it is not a guaranteed fact-checking system. It should be used as a supporting tool rather than an authority.

## Limitations

- model performance depends heavily on the quality of the dataset
- different writing styles can confuse the classifier
- unseen text may not match the original training distribution
- AI analysis may be helpful but not always accurate
- real-world fact checking still requires human verification and trusted sources

## Future Improvements

- improve dataset diversity and quality
- add validation and evaluation metrics
- use a larger or more balanced dataset
- experiment with stronger models
- connect Gemini with source checking or web search for better evidence review

## Conclusion

This project demonstrates how to build a fake news detection application using a machine learning model, a Flask backend, and a simple frontend interface. It also shows how an LLM can be added as an extra analysis layer for AI-assisted interpretation of unseen text.
